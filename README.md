# Healthcare Claims & Revenue Performance Analysis

An interactive dashboard covering Executive Summary, Denial Analysis, Payer & Revenue, and Provider & Patient performance.

## 📌 Project Overview

This Business Analyst portfolio project focuses on analysing healthcare claims, revenue performance, insurance denials, payer trends and provider performance.

The objective is to identify patterns in claim processing, understand the reasons behind claim denials, evaluate payer payment performance and generate actionable business insights.

## 🛠️ Tools & Technologies

- **SQL:** Data querying and analytical investigation.
- **Microsoft Excel:** Dataset organisation and analysis.
- **HTML, CSS and JavaScript:** Interactive dashboard development.
- **GitHub Pages:** Dashboard hosting and publishing.

## 📂 Project Structure

- `Healthcare_Claims_Analysis.sql` – Main SQL analysis file.

## 🔍 Key Business Findings

- Total claims analysed: 4,737.
- Total denied claims: 426.
- Overall denial rate: approximately 8.99%.
- Total billed amount: approximately $18.03 million.
- Total paid amount: approximately $7.94 million.
- Medical necessity was the most frequent denial reason.
- Commercial payer contributed the highest billed amount.

## 💡 Business Recommendations

- Investigate recurring medical necessity denials.
- Improve documentation and claim submission quality.
- Monitor payer-wise denial and payment performance.
- Track payment turnaround to identify collection delays.
- Regularly evaluate provider and facility performance.

## 🗃️ Dataset Information

The project uses a synthetic healthcare dataset generated by Misata Studio. It contains seven CSV data tables covering patients, providers, encounters, diagnoses, claims, prescriptions and laboratory results.

The dataset contains no real patient information, according to its supplied documentation.

The Excel workbook contains four related tables used in the project analysis.
